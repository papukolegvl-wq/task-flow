# TaskFlow - Интерфейс Управления Задачами

![TaskFlow Preview](preview.png)

## 📋 Описание

TaskFlow - современное веб-приложение для управления задачами с поддержкой иерархии, зависимостей, статусов и приоритетов. Создано для эффективной декомпозиции и организации как личных, так и рабочих задач.

## ✨ Основные возможности

### Реализовано (v1.0)

- ✅ **Создание и редактирование задач** - полнофункциональный редактор с поддержкой описаний, статусов и приоритетов
- ✅ **Иерархия задач** - неограниченная вложенность подзадач с визуальным отображением
- ✅ **Статусы задач** - Бэклог, В работе, Ожидание, Выполнена, Есть сложность, Отменена
- ✅ **Приоритеты** - Низкий, Средний, Высокий, Критичный
- ✅ **Теги** - гибкая система меток для категоризации
- ✅ **Срок выполнения** - отслеживание дедлайнов
- ✅ **Поиск** - быстрый поиск по всем задачам
- ✅ **Статистика** - отображение количества задач по статусам
- ✅ **Режим списка** - иерархическое отображение задач с разворачиванием
- ✅ **Модальное окно редактирования** - удобный интерфейс для работы с задачами
- ✅ **Адаптивный дизайн** - поддержка светлой и темной темы

### В разработке (v2.0)

- 🚧 **Канбан-доска** - визуализация задач в виде колонок с Drag & Drop
- 🚧 **Календарь** - просмотр задач в календарном представлении
- 🚧 **Зависимости между задачами** - управление связями и блокировками
- 🚧 **Вложения** - прикрепление файлов и ссылок
- 🚧 **Комментарии** - обсуждение задач
- 🚧 **История изменений** - отслеживание всех изменений
- 🚧 **Экспорт** - сохранение в Markdown, JSON, текст
- 🚧 **Импорт** - загрузка задач из файлов
- 🚧 **Автоматизация** - правила для автоматической смены статусов
- 🚧 **Повторяющиеся задачи** - настройка регулярных задач
- 🚧 **Уведомления** - напоминания о дедлайнах

## 🚀 Быстрый старт

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для production
npm run build

# Предпросмотр production сборки
npm run preview
```

Приложение будет доступно по адресу: **http://localhost:5173**

## 🛠 Технологический стек

- **React 18** - UI библиотека
- **TypeScript** - типизация
- **Zustand** - управление состоянием
- **Vite** - сборщик и dev-сервер
- **Lucide React** - иконки
- **CSS Variables** - темизация
- **date-fns** - работа с датами
- **UUID** - генерация уникальных ID

## 🎨 Дизайн

TaskFlow использует современный минималистичный дизайн с акцентом на удобство использования:

- **Цветовая схема** - Indigo/фиолетовые акценты (#6366f1)
- **Темная тема** - автоматическое переключение по системным настройкам
- **Типографика** - Inter шрифт для максимальной читаемости
- **Анимации** - плавные переходы и эффекты наведения
- **Адаптивность** - корректное отображение на разных экранах

## 🔑 Горячие клавиши (планируется)

- `N` - Новая задача
- `Ctrl/Cmd + S` - Сохранить
- `Ctrl/Cmd + F` - Поиск
- `Esc` - Закрыть модальное окно

## 📊 Управление данными

Сейчас данные хранятся в памяти (Zustand store). В следующих версиях планируется:

- LocalStorage для локального сохранения
- Backend API для синхронизации
- Экспорт/импорт в различных форматах
